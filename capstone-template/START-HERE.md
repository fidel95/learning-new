# Capstone template

How to use this folder:

1. Create a NEW, empty repository on GitHub for your capstone (private is fine).
2. Copy everything in this folder (including the hidden `.github` and `.gitignore`) to its root.
3. Run `npm test` (it should pass), then `npm start` and open http://localhost:3000/health
4. Fill in `DESIGN.md` first. Then build milestone by milestone, the plan is in lesson 15 of the book.
5. Delete this file when you are done.
